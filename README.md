# Superstore Sales Dashboard - Excel

## Project Overview
This project analyzes Superstore sales data using Excel dashboards and visualizations.

## Features
- Region-wise sales analysis
- Category performance
- Monthly sales trends
- KPI cards
- Interactive charts

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
